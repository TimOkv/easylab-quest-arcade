# EasyLab Quest & Endless Arcade

Интерактивный веб-модуль для онлайн-школы **Easycode** (`easycode-lab.ru`). Ученик 6–17 лет:

1. водит котика **Изика** по **4 комнатам** его дома — Спальня, Кухня, Библиотека, Чердак — и решает **8 загадок** про код,
   по 2 в каждой комнате (переменные, IF/ELSE и `&&`, циклы FOR/WHILE, функции и аргументы). Изик ходит стрелками/WASD
   или по клику/тапу на пол, загадка открывается у предмета; когда обе загадки решены, открывается дверь в следующую комнату;
2. получает **EasyCoins** (до 150: по 2 загадки × 10 + 15 + 20 + 30) — сколько именно, зависит от попыток и подсказок;
3. на экране триумфа видит **личный ID `EZ-XXXX`** — его он присылает куратору;
4. открывает **аркаду** (бесконечный вертикальный прыгун) и борется за **ТОП-3 рейтинга сезона** — призы и мерч Easycode.

Квест проходится **один раз**: после финиша при любом повторном открытии сразу открывается аркада, монеты заново не начисляются.
В момент финиша прохождение само уходит в **реестр куратора** (Supabase, по желанию — ещё и в Google-таблицу), где куратор
находит ученика по коду и видит, сколько монет начислить.

Модуль работает сам по себе и внутри платформы EasyLab в `iframe` — тогда он получает имя и ID ученика и сообщает платформе
о монетах, коде и рекорде (см. [docs/INTEGRATION.md](docs/INTEGRATION.md)).

## Быстрый старт

Нужен Node.js 20+ (проверено на Node 24).

```bash
npm install
npm run dev          # http://localhost:5173 — модуль
                     # http://localhost:5173/verify.html — кабинет куратора
                     # http://localhost:5173/parent_test.html — стенд интеграции с EasyLab
```

Сборка для выкладки:

```bash
npm run build        # проверка типов + сборка в dist/
npm run preview      # посмотреть собранную версию локально
npm run check:size   # проверка бюджета: dist/ не больше 1,8 МБ
```

Папку `dist/` можно положить в любую подпапку сайта или на CDN — все пути относительные (`./`).
**Фактический размер сборки: 0,67 МБ** при лимите 1,8 МБ (из картинок — только 4 фона комнат и аватарка Изика в webp); звуковых файлов нет — 8-битная музыка и эффекты синтезируются в браузере.

## Демо-режим

Если адрес и ключ Supabase не заданы, модуль работает в **демо-режиме**: квест проходится, код `EZ-XXXX` выдаётся,
аркада играется, прогресс хранится в браузере. Но реестра куратора и общего рейтинга нет: на триумфе и в рейтинге
честно написано «демо-режим», сеть не используется. Так удобно показывать проект до настройки базы.

## Переменные окружения

Задаются в файле `.env` в корне (образец — `.env.example`) **до сборки**: значения вшиваются в `dist/`, после изменения нужна пересборка.

| Переменная | Зачем | Пример |
|---|---|---|
| `VITE_SUPABASE_URL` | адрес проекта Supabase (реестр куратора, рейтинг) | `https://<ваш-проект>.supabase.co` |
| `VITE_SUPABASE_ANON_KEY` | публичный anon-ключ Supabase (его можно отдавать в браузер; доступ ограничен правилами базы) | `<ваш-anon-ключ>` |
| `VITE_BRIDGE_EXTRA_ORIGINS` | необязательно: дополнительные адреса родительских страниц для `postMessage` (через запятую; маска `https://*.домен`) — например, стенд платформы | `https://staging.partner.example` |

Секрет куратора и секрет Google-таблицы в `.env` **не кладутся** — они задаются в базе и в скрипте таблицы (см. инструкции).
Настоящие ключи не коммитьте: `.env` уже в `.gitignore`.

## Как куратор проверяет ученика

1. Ученик присылает код с экрана триумфа, например `EZ-7K3M`.
2. Куратор открывает свою ссылку `https://<адрес-модуля>/verify.html#k=<секрет-куратора>` (секрет — после `#`, на сервер не уходит;
   `<адрес-модуля>` — адрес, где выложена сборка, его подставляет команда EasyLab),
   вставляет код → видит «Квест пройден. Заработано: **X** EasyCoins», имя, ID, дату (МСК).
3. Начисляет X монет в EasyLab и жмёт «Отметить коины как начисленные».
4. Во вкладке «Рейтинг и сезон» — таймер сезона, дневной лимит очков, скрытие неприличных ников, «Подвести итоги», прошлые победители.

Альтернатива — Google-таблица: строка появляется сама в момент финиша, поиск по коду через `Ctrl+F`.

## Правила игры (где настраиваются)

| Что | Где |
|---|---|
| Монеты за загадку (в комнатах 1–4 — 10 / 15 / 20 / 30): 1-я попытка — 100 %, 2-я — ~70 %, 3-я и дальше — 50 %; первая подсказка (открывается после первой попытки) бесплатна, вторая («почти ответ») обнуляет монеты загадки | `src/core/rules.ts` (`PUZZLE_REWARDS`, `rewardFor`) |
| Формат кода `EZ-XXXX` (буквы и цифры без похожих 0/O, 1/I) | `src/core/rules.ts` (`generateVerificationCode`) |
| Античит: ≤ 120 очков/с, забег ≥ 5 с, счёт ≤ 50 000, ник 2–16 символов | `src/core/rules.ts` + проверка на сервере в `supabase/schema.sql` |
| Тексты и ответы загадок | `src/quest/puzzles.ts` |
| Сюжет, ходьба Изика, двери, триумф | `src/quest/screen.ts` |
| Разметка комнат: мебель, предметы с загадками, двери | `src/quest/world/rooms.ts` |
| Физика и сложность аркады | `src/arcade/engine.ts` |
| Рейтинг: очки засчитанных забегов складываются за сезон; сезон, таймер и дневной лимит меняет куратор | `supabase/schema.sql`, кабинет `verify.html` |
| Белый список адресов платформы | `src/services/bridge.ts` + `VITE_BRIDGE_EXTRA_ORIGINS` |

## Структура

```
index.html, verify.html, parent_test.html   три страницы сборки
src/
  core/         состояние (localStorage «ezq_save_v1»), правила монет/кода/античита, общие типы
  app/          оболочка: экран 16:9 / 450×800, safe-area, блокировка зума и свайпов, роутер, проводка сервисов
  quest/        экран квеста: 8 загадок, подсказки, HUD монет, двери, триумф
  quest/world/  разметка 4 комнат, поиск пути (A*), пиксельный Изик, логотип Easycode
  arcade/       движок (фиксированный шаг 1/60 с), пиксельные спрайты, экран аркады
  leaderboard/  рейтинг сезона с ТОП-3
  services/     REST к Supabase (нативный fetch), реестр куратора, рейтинг с офлайн-очередью, мост EasyLab, звук
  verify/       кабинет куратора
  parent-test/  стенд интеграции
  assets/rooms/     фоны 4 комнат (webp); assets/rooms/src/ и assets/room.jpg — исходники для scripts/prep-rooms.py, в сборку не идут
  assets/cat-avatar.webp  аватарка Изика рядом с его репликами
supabase/schema.sql                     таблицы, защита (RLS), серверные функции
integrations/google-apps-script/Code.gs приёмник строк для Google-таблицы
docs/                                   инструкции
scripts/                                проверка размера сборки, подготовка фонов комнат
tests/                                  unit-тесты (vitest), tests/e2e/ — сквозные (Playwright)
```

Стили изолированы: все классы начинаются с `ezq-`, глобальных стилей на `html`/`body`/теги нет (проверяет тест `tests/css-prefix.test.ts`).
Рантайм-зависимостей нет — только Vite, TypeScript и Canvas.

## Тесты

```bash
npm test             # unit-тесты: правила, состояние, квест, движок, сервисы, SQL-схема (в PGlite)
npm run test:e2e     # сквозные в Google Chrome на собранной сборке (сам собирает и поднимает vite preview)
```

`npm run test:e2e` собирает две версии (в `node_modules/.ezq-e2e/`, ваш `dist/` не трогается) и поднимает `vite preview` на портах **5231** (демо-режим) и **5232**
(та же сборка с фиктивным адресом Supabase — запросы `/rest/v1/*` подменяет тест). Проверяется на экранах 1440×900 и 844×390 (телефон в горизонтали):

- квест с ошибками и подсказками → точная сумма монет по формуле, триумф с кодом `EZ-XXXX`, запись в реестр куратора;
- перезагрузка → сразу аркада, квест недоступен, код и монеты на месте, повторной записи в реестр нет;
- забег → рейтинг ТОП-10 с призовыми бейджами и своей строкой; рекорд переживает перезагрузку;
- кабинет куратора находит ученика по коду и показывает фактические монеты;
- стенд `parent_test.html` получает `EASYLAB_QUEST_COMPLETED` (точные монеты, код, ID ученика) и `EASYLAB_GAME_FINISHED`;
- телефон: щипок, двойной тап и свайпы не масштабируют и не прокручивают страницу, горизонтальной прокрутки нет;
- аватарка Изика видна целиком на ПК, ноутбуке, iPhone, Android, iPhone SE и iPad (`tests/e2e/avatar.spec.ts`);
- аркада держит ≥ 55 FPS (`tests/e2e/arcade.spec.ts`).

Нужен установленный Google Chrome (браузеры Playwright не скачиваются). Скриншоты ключевых экранов
в репозиторий не входят — снять их в `tests/e2e/__screenshots__/`: `EZQ_FINAL_SHOTS=1 npm run test:e2e`.
