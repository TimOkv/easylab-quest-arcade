## Откуда

Слепая приёмка (G4) и разбор отложенных замечаний ревью. Слепой проверяющий: «на холодильнике маленький синий знак размером с сам магнит; слова easycode на нём не видно» — R09 считался готовым. Зашитые цвета мимо токенов повторились в трёх тасках (03, 05, 06) — это уже не вкус, а несоблюдённое соглашение. Проверка «старое прохождение» по `maxPossibleCoins === 75` / `=== 150` живёт в трёх местах и в одном из них даёт ошибку.

## Критерии приёмки

- [ ] **Магнит на холодильнике читается как Easycode**: на ПК-скриншоте кухни логотип магнита различим (знак + слово «easycode» или узнаваемый фирменный вариант из `quest/world/brand`), при этом это по-прежнему магнит на дверце холодильника, а не плакат; на телефоне в горизонтали он тоже различим. Посмотри глазами.
- [ ] **Цвета — токенами.** В `src/quest/quest.css`, `src/quest/screen.ts` и в состоянии «музыка выключена» кнопки 🎵 (`src/app/shell.ts`, сейчас inline-стили с зашитым цветом) нет зашитых hex/rgba там, где есть или должен быть токен `--ezq-*`; новые цвета объявлены токенами на `.ezq-root` в `src/app/app.css` (и, где нужно, в светлой теме `.ezq-root[data-ezq-theme="light"]`). Фирменный синий берётся из одного источника. Затемнение перехода не повторяет 1600/900 px, а берёт размер сцены. Внешний вид не меняется (сравни скриншоты `walk-*` и `final-*` до и после).
- [ ] **«Старое прохождение» — одно понятие в `src/core/`** (функция или поле), и им пользуются все места, где сейчас сравнивают с 75/150: `src/app/app.ts` (выбор `puzzles` для payload моста), `src/quest/screen.ts` (текст триумфа), `src/services/curator.ts`. Прохождение, восстановленное с сервера (`restoreByStudent`, свои монеты без записей по загадкам), не отдаёт в `EASYLAB_QUEST_COMPLETED` 8 нулевых записей `puzzles` при ненулевом `coinsEarned` — тест на это. Тест на текст триумфа для старого прохождения на 75.
- [ ] **Кухня без артефакта закраски**: светлый прямоугольник у стены (≈1300×100 в исходнике, правый верх кухни) убран через `scripts/prep-rooms.py`, разметка `src/quest/world/rooms.ts` остаётся валидной.
- [ ] **3 ответа 404 в консоли** при запуске `npx vite` и открытии квеста на ПК: найди, какие это запросы; если это файлы проекта — исправь; если это браузерный `favicon.ico` или подобное вне кода — напиши одной строкой, что это.
- [ ] `npm run build`, `npm test`, `npx playwright test`, `npm run check:size` зелёные; `EZQ_FINAL_SHOTS=1 npx playwright test tests/e2e/acceptance.spec.ts` перезаписывает скриншоты.
