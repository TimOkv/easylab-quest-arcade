## Что должно заработать

Модуль собран целиком: квест → триумф → аркада → рейтинг и обратно, по охраняемым маршрутам. На финише квеста запись улетает куратору (с повторами), платформа получает `EASYLAB_QUEST_COMPLETED`; после каждого забега — отправка в рейтинг (или очередь) и `EASYLAB_GAME_FINISHED`. Экран рейтинга: призовая шапка, ТОП-10 с бейджами, своя позиция и отставание, дневной лимит, отсчёт до итогов, карточка последнего забега. Во встраивании модуль шлёт `EASYLAB_READY`, ждёт `AUTH_INIT`, восстанавливает прошедшего ученика по ID. Стенд `parent_test.html` показывает всё это вживую.

## Критерии приёмки

- [ ] `createBridge` + `isAllowedOrigin`: `https://easycode-lab.ru`, `https://*.easycode-lab.ru` (не `evil-easycode-lab.ru`, не `easycode-lab.ru.evil.com`, не `http:`), собственный origin, `VITE_BRIDGE_EXTRA_ORIGINS`; конверт `{source:'ezq', version:1, type, payload}`; исходящие только на проверенный origin; вне iframe — ничего не шлёт; тесты на фейковом window
- [ ] Старт: во встраивании `EASYLAB_READY` + ожидание AUTH_INIT ≤ 1.5 с на экране загрузки (знак «загрузки»); AUTH_INIT → `platformStudentId`, имя, тема; G03 `restoreByStudent` → переход в аркаду с тостом
- [ ] Проводка: завершение квеста → `curatorSync.syncNow()` + `startRetryLoop` + `EASYLAB_QUEST_COMPLETED` (точные монеты, код, по комнатам); game over → `leaderboard.submitRun` + `EASYLAB_GAME_FINISHED` + переход на рейтинг с `lastRun`; `flushQueue` на старте/`online`
- [ ] `mountLeaderboardScreen`: шапка-призы, ТОП-10 (бейджи 🥇🥈🥉 + отметки, 4–10 стандарт, своя строка подсвечена), закреплённая строка своей позиции «Ты — N-й … До ТОП-10 — M», «Сегодня в рейтинг: X / лимит», отсчёт до итогов / «Сезон завершён», карточка последнего забега («+N в рейтинг», «лимит набран», «не засчитан — слишком короткий», «ждёт интернета», демо), скелетон/пусто/ошибка с кэшем, авто-обновление 20 с; ники только `textContent`; диалог смены ника при `BAD_NAME`
- [ ] `parent_test.html`: iframe модуля, форма AUTH_INIT (studentId, name, theme), журнал сообщений с временем и JSON, «Сбросить сохранение модуля»; работает в `dev` и `preview`
- [ ] Тест проводки (happy-dom или e2e): полный путь квест → аркада с фейковыми сервисами публикует оба события моста с правильными данными
