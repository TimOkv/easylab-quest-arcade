# Спецификация: Изик гуляет по дому — 4 комнаты, 8 загадок, 8-бит музыка

## Задача

Квест сейчас — одна картинка комнаты, по которой ездит камера, и четыре загадки, открывающиеся нажатием на подсвеченный предмет. Ученику не хватает ощущения игры: он не управляет героем, не ходит по комнатам, не видит, как проходит дальше. Комната одна на весь квест, загадок всего четыре, музыки нет.

## Решение

Ученик сам водит котика **Изика** (рыжий, в тёмно-синем худи со значком Easycode) по четырём разным комнатам дома: **спальня → кухня → библиотека → чердак**. На телефоне — тап по полу (Изик идёт туда в обход мебели), на ПК — стрелки/WASD или клик мышью. В каждой комнате два светящихся предмета с загадками; подходишь — над предметом кнопка «Пройти задачу». Две загадки решены в любом порядке → дверь светится, плашка «Быстрее пройди в дверь — следующая комната открыта!» и стрелка → ученик ведёт Изика к двери → Изик уходит в дверь, круг-затемнение сходится на нём и раскрывается уже в новой комнате, где он входит через её дверь.

Всего 8 загадок (4 прежние с новыми текстами + 4 новые), максимум **150 EasyCoins**. 1–2 декоративных предмета в комнате реагируют облачком и звуком. Бренд Easycode — точечно: экраны компьютеров включаются с логотипом, значок на худи, магнит на холодильнике, постер на чердаке. В квесте и аркаде играет 8-битная музыка (синтез, без файлов), отдельная кнопка 🎵 рядом с 🔊. На телефоне в вертикальном положении квест просит повернуть телефон. Всё остальное (код EZ-XXXX, триумф, одноразовость, куратор, аркада, рейтинг, мост) работает как раньше.

## Решения по реализации

1. **Фоны — подготовленные растровые картинки 1600×900.** Разовый скрипт подготовки (Python + Pillow, есть на машине; в сборку не входит, лежит в `scripts/`) берёт 4 исходника (`src/assets/room.jpg`, `IMG_0989.JPG`, `IMG_0991.JPG`, `IMG_0993.JPG`), вписывает каждый в 1600×900 по правилу contain на тёмный фон исходника, закрашивает нарисованного котика клоном пола рядом и заливает кнопки UI в углах цветом фона, сохраняет `src/assets/rooms/{bedroom,kitchen,library,attic}.webp` (качество ≈ 82). *Почему:* координаты всех комнат — в одной системе (пиксели сцены), сборка без обработки картинок, WebP держит бандл < 1,8 МБ. Исходники `IMG_09*.JPG` переезжают в `src/assets/rooms/src/` и в бандл не попадают; `room.jpg` больше не импортируется. Скрипт идемпотентен; координаты заплаток заданы в нём явно.
2. **Сцена комнаты = DOM-слой + canvas.** В сцене 1600×900: `<img>` фона → слой подсветок/бренд-оверлеев (DOM, inline SVG) → `<canvas>` 1600×900 для Изика, тени, метки цели и частиц → слой кнопок/облачков/плашек (DOM). *Почему:* кнопки и тексты остаются доступным DOM (фокус, `textContent`), а 60 fps анимация героя — на canvas. Масштаб — существующий `fitStage` (contain, letterbox), `image-rendering: pixelated` на canvas.
3. **Данные комнат — чистая таблица.** Для каждой комнаты: фон, название, прямоугольники/многоугольник пола, препятствия (прямоугольники мебели), предметы (id, прямоугольник для тапа и свечения, точка подхода, радиус, `puzzleId` или `decor`, бренд-оверлей), дверь (прямоугольник, точка входа/выхода, направление ухода), точка появления. Проходимость — сетка 20×20 px, строится из пола минус препятствия при загрузке комнаты. *Почему:* разметку можно выверять по скриншотам и тестировать без DOM.
4. **Ходьба — чистый модуль.** Поиск пути A* по сетке с 8 направлениями (диагональ без срезания углов препятствий) и сглаживанием линией видимости; шаг героя на фиксированном dt 1/60 с, скорость ≈ 260 px/с сцены; клавиатура — непрерывный вектор с проверкой коллизий по сетке, скольжение вдоль стены. Направление спрайта — по преобладающей оси скорости. Часы фиксированного шага — существующие часы аркады, вынесенные в общий модуль `core` (аркада импортирует оттуда же).
5. **Спрайт Изика — процедурный пиксель-арт.** Кадры рисуются в offscreen-canvas один раз при старте (как спрайты аркады): сетка ≈ 20×28 «пикселей», масштаб ×3 (≈ 60×84 px сцены — как нарисованный котик на исходниках). Направления: вниз, вверх, вбок (влево — отражение); кадры: стоя (2: дыхание), моргание, шаг (4). Палитра: рыжий #E8893A / тень #B8612A, белый #FFF6EC, тёмно-синее худи #1E2A55 / #2E3F7A, розовый нос #F29A9A, глаза #1B1B1B; на груди худи — знак «загрузки» из 7 голубых/белых пикселей-штрихов.
6. **Логотип Easycode — inline SVG-константа.** Знак «загрузки» (7 скруглённых штрихов по кругу, без верхнего левого) + слово «easy» (белым на тёмном экране) и «code» (#0068FF). Один компонент, варианты «экран», «магнит» (только знак на белом круге), «постер» (знак + слово на синем #0068FF). *Почему:* брендбук п. 2.1/2.7 — знак можно отдельно, слово без знака — нельзя.
7. **Состояние — расширение `EasyQuestGameState`.**
   - `quest.puzzles: Record<PuzzleId, { earnedCoins; isSolved; attempts; hintsUsed }>` — 8 записей.
   - `quest.rooms[n]` остаётся для совместимости: `isSolved` = обе загадки решены, `earnedCoins`/`attempts`/`hintsUsed` = суммы, `maxReward` = сумма пулов (20/30/40/60). Тип литералов `maxReward`/`title` расширяется до `number`/`string`.
   - `quest.maxPossibleCoins: 75 | 150` — новое 150; у старых завершённых остаётся 75 из сохранения.
   - `quest.format: 2` — метка формата квеста.
   - `navigation.isMusicMuted: boolean` (по умолчанию `false`).
   - Миграция при загрузке: сохранение без `quest.format === 2` и с `quest.isCompleted !== true` → квест сбрасывается к начальному (ник, `meta`, `navigation.isAudioMuted`, `leaderboard.playerName` сохраняются; `currentRoomIndex = 1`); завершённое — не трогается, только дополняется значениями по умолчанию.
8. **Контроллер квеста работает по загадкам.** `submit(puzzleId, answer)`, `useHint(puzzleId)`, `canUseHint(puzzleId, level)`, `currentReward(puzzleId)`, `isRoomCleared(room)`, `advance()` — только если обе загадки текущей комнаты решены. Загадка доступна, если её комната = текущая. Завершение — в том же `update`, где решена последняя из 8 (и все остальные решены): как сейчас ставит `isCompleted`, `completedAt`, `verificationCode`, `arcade.isUnlocked`. Попытка пишется до показа результата (как сейчас).
9. **Музыка — отдельный сервис рядом с `sfx`.** Секвенсор на WebAudio: 2 темы (квест — 90 BPM, треугольник + квадрат 25%, мажор, мягкий бас; аркада — 140 BPM, квадрат 50% + шумовые хэты), ноты — таблица в коде, планирование «на 100 мс вперёд» по таймеру. Общий `AudioContext` с `sfx` (одна разблокировка по жесту). API: `play('quest' | 'arcade')`, `stop()`, `duck(on)`, `unlock()`. Уважает `navigation.isMusicMuted` на лету и `visibilitychange`.
10. **Кнопка 🎵** — рядом с существующей 🔊, тем же способом (в `shell`), `aria-pressed`, подписи «Выключить музыку / Включить музыку».
11. **Сервер: максимум 150 и `coins_max`.** `supabase/schema.sql` остаётся идемпотентным: CHECK `coins_earned` → `0..150` (пересоздание ограничения по имени), `register_quest_completion` принимает `p_coins` до 150; новая колонка `quest_completions.coins_max integer` — существующим строкам 75, новым 150 (сервер ставит 150 при регистрации); `restore_by_student` и `curator_find`/`curator_recent` возвращают `coins_max`; вебхук Google-таблицы шлёт `coins_max`, `Code.gs` пишет «N из M». Кабинет куратора показывает «Заработано N из M». Сигнатура `register_quest_completion` не меняется.
12. **`BAD_COINS` — безнадёжный отказ** в `curator.syncNow`: повтор не планируется, `lastSyncError = 'BAD_COINS'`, экран показывает «Реестр не принял данные — покажи код куратору».
13. **Мост** — только расширение: `maxCoins: number` (из `quest.maxPossibleCoins`), `rooms` — 4 записи-суммы как раньше, новое поле `puzzles: [{ id, room, earnedCoins, maxReward, attempts, hintsUsed }]` (8 записей; у старых завершённых — пусто). `parent_test.html` показывает «N / M».
14. **Портрет** — оверлей «Поверни телефон 🔄» в экране квеста по `matchMedia('(orientation: portrait) and (pointer: coarse)')`; пока он виден — ходьба и таймеры анимации на паузе.
15. **Тексты интерфейса** — «из 75» нигде не захардкожено: HUD, триумф, профиль аркады, куратор берут максимум из состояния/записи. `MAX_TOTAL_COINS = 150` в `rules.ts`.
16. **Документация**: `docs/INTEGRATION.md` (payload, 150), `docs/SUPABASE_SETUP.md` (перезапуск schema.sql), `docs/GOOGLE_SHEETS.md`, ADR 0004 дополняется (формула на 8 загадок); `CLAUDE.md` — только внутри блока autopilot.
