## Что должно заработать

Экран аркады: профиль ученика (имя, код с копированием, «Заработано X из 75»), кнопка «Играть» и холст 450×800. Рыже-белый пиксельный котик в тёмно-синем худи прыгает по процедурным платформам (статичные → движущиеся → исчезающие), ловит пружины и ракеты, видит метки высоты и линию своего рекорда, вылетает слева и появляется справа. Физика с фиксированным шагом одинакова на любой частоте экрана. Падение ниже камеры завершает забег: store обновлён, наружу уходит `RunResult`.

## Из брифа, дословно

> «Фиксированный физический шаг дельта-тайминга (`fixed delta time = 16.6ms`)»
> «Процедурная генерация платформ с детерминированным сидом и возрастающей сложностью (статичные → движущиеся → исчезающие).»
> «Горизонтальный Screen Wrapping»
> «Десктоп: стрелки `ArrowLeft` / `ArrowRight`, клавиши `A` / `D`. Мобилки: разделенный экран (левая половина — влево, правая — вправо) с мягким визуальным тач-откликом.»
> «сгенерируй процедурную пиксельную графику прямо через Canvas API»
> «Без монеток в аркаде» / «Ракета-бустер, Пружины-батуты, Метки высоты»

## Критерии приёмки

- [ ] `createWorld(seed)`/`stepWorld` детерминированы (один сид → одинаковый мир и траектория); тесты: коллизия только при падении и без туннелирования при большом `vy`; wrap; пороги сложности по высоте; проходимость (зазор < 85% высоты прыжка, неисчезающая опора в каждом поясе) на 100 сидах; бот по лучшей траектории на 100 сидах держит среднюю скорость < 100 очков/с
- [ ] Цикл: аккумулятор 1/60 с, ≤ 5 шагов за кадр, интерполяция, пауза при `visibilitychange`/потере фокуса, кнопка паузы + `Escape`/`P`; горячий цикл без аллокаций (пулы)
- [ ] Спрайты — матрицы пикселей → offscreen canvas: котик (стоит/прыжок/падение, отражение), 3 вида платформ, пружина (сжатие), ракета + пламя, фон с переходом к звёздному небу и параллаксом; ни одного файла изображения
- [ ] Ввод: `event.code` для стрелок/A/D; pointer-мультитач по половинам с подсветкой нажатой половины и стрелками-подсказками; `touch-action:none` на холсте
- [ ] Метки высоты каждые 500 очков + линия «Твой рекорд» + вспышка «Новый рекорд!»; очки = `floor(maxHeightPx/10)`; звуки jump/spring/rocket/gameover
- [ ] При game over экран обновляет `arcade.highScore, totalRunsPlayed, lastRun{runId, score, durationSeconds, jumpsCount, timestamp, seed}` и зовёт `onGameOver(RunResult)`; e2e (Playwright `channel:'chrome'`) замеряет ≥ 55 FPS и ≤ 4 мс на step+render в среднем за 5 с
